#
# Conventions in force for this file:
#   * One token per chanted word (a maqaf compound is one word, so one token).
#   * A postpositive/prepositive accent written twice on one word -- once at its fixed edge
#     and once as a stress helper -- is ONE accent, so ONE token.
#   * meteg is NOT transcribed: it is not a first-class mark of the accent system.
#   * narrow-sense paseq is likewise not transcribed.  Where a paseq-like vertical does bear
#     on the accent system -- munax legarmeh -- it is written "mun_leg".  Bracketed asides
#     such as "[page break]" carry no accent and are ignored by the parser.
#
# Shorthand: etn etnaxta / seg segolta / zaq zaqef qatan / zaqg zaqef gadol / tip tipexa /
