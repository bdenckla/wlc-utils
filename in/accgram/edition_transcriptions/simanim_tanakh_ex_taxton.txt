# One .txt line per PRINTED line, so a token can be checked against the line it was read off.

# THE FIRST TRANSCRIPTION DIFFED AGAINST A MANUSCRIPT-TRADITION STRAND.  The eight before it --
# Simanim Tiqqun's four and Koren's four -- are all against a printed-tradition strand.  This is
# a different edition from the Tiqqun though Feldheim publishes both, and its Decalogues are
# m-trad; printed_decalogue_simanim_page.py had already recorded that for Exodus, naming this
# very page, with a committed crop (gh-pages/accgram/img/Simanim-Tanakh-p-119-*) highlighting
# עבדים and על־פני.  This transcription is the accent-by-accent check of that reading.
#
# RESULT: 142 reference tokens vs 142 transcribed, 12 chanted verses vs 12, and NO divergence
# anywhere.  The single pasoleg stroke, on אתה in the Shabbat commandment, lands on its exact
# reference position (token 80).  So "follows ex/taxton/manuscript with respect to every accent"
# is true of this Decalogue -- the third transcription for which the strong claim holds.
#
# THE CROSS-STRAND RE-RUN, and it carries more weight here than the clean result does.  Against
# ex/taxton/printed this transcription is 142 tokens against 142 but 13 chanted verses against
# 12, with THREE difference regions, all inside the first commandment:
#   * אנכי       -- pashta here, tipexa in the p-trad
#   * אלהיך      -- zaqef qatan here, etnaxta in the p-trad
#   * מבית עבדים -- munax + etnaxta here, merkha + silluq/sof pasuq in the p-trad, so the p-trad
#                   closes a chanted verse at עבדים and this page runs on into לא־יהיה לך,
#                   closing only at על־פני
# The transcription takes the m-trad side of all three, over a contiguous run nothing had
# flagged.  The edition's OWN printed verse numbers corroborate it mark-free: the Decalogue is
# numbered ב-יג, twelve verses, matching the m-trad's twelve and not the p-trad's thirteen.
#
# HOW NARROW THAT VERDICT IS, stated because the clean result invites overreading it.  The two
# ex/taxton strands differ in EXACTLY those three regions and nowhere else in 142 tokens -- taken
# before any transcription existed, so with no stake in the outcome.  Tokens 9-141, the other
# 133, are identical in both traditions, so the whole stretch from לא־יהיה to לרעך is evidence
# that this page follows ex/taxton, and no evidence at all about which tradition.  The Exodus
# taxton is as weak a discriminator here as it was for Koren (issue #69 Result 5), only mirrored.
# Worse, at all three sites ex/taxton/manuscript agrees with ex/elyon/printed and vice versa, so
# the sites separate tradition only GIVEN the strand; the taxton identity itself rests on the
# independent evidence at לא תרצח, which this Decalogue runs into one chanted verse with לא תנאף
# and לא תגנב, as all four taxton strands do and no elyon strand does.
#
# TWO PAGES, and the break is not where issue #72's step-0 comment puts it.  That comment has
# p. 120 opening at לך: and carrying לא תרצח onward.  It does not: p. 119 runs through
# לך: לא תרצח לא תנאף לא תגנב and ends on the bare לא־ of לא־תענה, and p. 120 opens at תענה.  So
# the break falls INSIDE a maqaf compound -- reference token 124, לֹֽא־תַעֲנֶ֥ה -- which is why
# p. 119's last band ends on the zaqef qatan of תגנב rather than on a silluq: that chanted verse
# closes on p. 120, at שקר.  The compound bears one accent, on its second atom, so nothing was
# typed for the לא־ and no cross-page rejoin was needed; had the edition accented the proclitic
# too, as the Tiqqun does at לא־יהיה and לא־תעשה (p. 246), rejoin_editor_chunks would have had
# to carry it across the page boundary.
#
# ONE CORRECTION, made after export against a re-cropped zoom and recorded in the JSON with what
# it replaced: p. 119 line 6, a skipped munax on אל (20:5), between the pashta of אלהיך and the
# zaqef qatan of קנא.  A transcription slip, not an edition divergence -- all EIGHT strands have
# munax there, so the site discriminates nothing, and it was the only difference that survived
# against BOTH ex/taxton strands, which is what marked it out as a slip rather than a finding.
#
# ONE BAND CLEARED, also recorded with what it replaced: p. 120 line 4.  The crop carries a
# context line below the Decalogue -- printed line 4, וכל־העם ראים … קול השפר (20:14) -- which
# was typed by mistake.  It is outside this transcription's span, which ends at לרעך:.  The
# export keeps the reading in corrected_from rather than discarding it.
#
# NO UNCERTAIN READING: nothing here was supplied from context or expectation.  The usual caution
# still applies and applies especially to a zero-divergence result: the harness flags only
# positions where the two already disagree, so on the m-trad run only the אל slip was ever
# re-read and the other 141 positions were not re-examined by anyone.  What carries weight is the
# cross-strand run above -- agreement over a contiguous run with a strand nothing had flagged --
# not the empty difference list.
#
# PASOLEG KINDS: "distinguished" here is an ASSUMPTION about the edition, not yet an observation,
# and this Decalogue cannot settle it.  ex/taxton has exactly ONE stroke in its whole span, on
# אתה, so there is no second stroke to contrast it with and no narrow-sense paseq was seen on
# these pages; the stroke is written mun_leg on the assumption that this edition draws the
# distinction its sibling the Tiqqun draws.  The Deuteronomy main-text Decalogue (pp. 297-298,
# issue #72's next box) has TWO stroke positions and is where the assumption can first be tested;
# if it fails, this file's mun_leg becomes "[pasoleg]" and the header field "not distinguished".
#
# The render crops in the JSON take the pointed text column only, measured from ink profiles
# rather than eyeballed and then verified band by band with the editor's --debug.  Both margins
# needed measuring on this edition: it sets ONE column, but the verse numbers sit in one margin
# and the sidenotes in the other (and which side is which flips with the leaf, both being the
# OUTER margin).  Each crop carries a context line the transcription does not use -- p. 119's
# first band (וידבר אלהים, 20:1, before the strand's own span begins at אנכי) and p. 120's
# fourth -- so that the outermost transcribed line's marks cannot be clipped.
#
# Conventions in force for this file:
#   * One token per ACCENT.  Normally that is one per chanted word, a maqaf compound being one
#     chanted word; the exception is a word bearing more than one accent.  None occurs here.
#   * "-" is a maqaf binding two ACCENTS into one chanted word ("mun-mer"), "+" its simple-word
#     counterpart, "_" binds two MARKS into ONE accent ("mun_leg").  Only "_" occurs here.
#   * A postpositive/prepositive accent written twice on one word -- once at its fixed edge and
#     once as a stress helper -- is ONE accent, so ONE token.
#   * meteg is NOT transcribed: it is not a first-class mark of the accent system.
#   * A narrow-sense paseq is not an accent and is not a token; it would be recorded as the aside
#     "[paseq]" after the token it follows.  None occurs here.  Legarmeh IS an accent, written
#     "mun_leg" -- one token, not an aside.
#
